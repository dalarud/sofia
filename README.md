# Studio Dalarud

Företagskoncept, grafisk profil och hemsida för Studio Dalarud: inredning, homestaging och föremål i lera, med kunskap om NPF. *Från brus till ro.*

| Mapp | Innehåll |
| --- | --- |
| `koncept/` | Företagskonceptet (`KONCEPT.md`) |
| `profil/` | Logotyp, typsnitt, grafisk manual och tryckfiler |
| `guide/` | Gratisguiden *7 saker för ett lugnare barnrum* |
| `index.html` | Den klickbara prototypen av hemsidan |
| `web/` | Den skarpa hemsidan med webbutik och administration. Se `web/README.md` för hur den startas och sätts i drift. |
